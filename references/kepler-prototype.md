# 迷你爱因斯坦测试：从第谷数据重新发现开普勒定律

第一个可执行实例（阶段 1）。目标不是"算出行星轨道"，而是验证**集体溯因循环**能否从冻结的零散观测中涌现出范式跃迁假说（椭圆轨道）。

## 1. 实验目标与隔离规则

目标：仅输入第谷原始行星观测坐标 + 欧几里得几何 + 基础代数，系统自主抛弃圆轨道旧假说，涌现椭圆轨道假说（开普勒第一定律），并继续推导第二、第三定律。

**隔离规则（数据冻结，红线）**：

- 训练/推理语料截止 1600 年：只含观测坐标、几何、代数、旧天文学（地心/本轮均轮可作旧理论）；
- 严禁出现：开普勒定律、椭圆轨道文字；"椭圆"不得作为输入特征或生成原语关键词；
- 输出审计：不得直接输出结论关键词；必须先出方程，再导出形态。

## 2. 原型架构（A–F 单元集群，仅局部通信）

无全局中央控制器；单元间只通过黑板工件交换状态。

| 集群 | 职责 | 输入 → 输出 |
|---|---|---|
| A 异常检测 | 拟合传统正圆模型，计算残差，标记「圆轨道与观测持续矛盾」 | 观测坐标 → 反常集合 $A$ |
| B 假说生成 | 基于几何原语生成候选轨道：圆、偏心圆、卵形、一般二次曲线……（大量错误） | $A$ → $H_{candidate}$ |
| C 数学推导 | 对每个候选轨道生成位置随时间的预测方程 | $h$ → $P_h$ |
| D 校验 | 预测坐标 vs 第谷真实观测，残差与一致性打分 | $P_h, O$ → $score_h$ |
| V 全局调制 | 用 $V(h)$ 打分：高残差/高复杂度淘汰；简洁 + 一致保留 | $score_h, V$ → $H_{survived}$ |
| E 重组 | 重组幸存假说的几何组件，生成下一代候选 | $H_{survived}$ → $H'$ |

## 3. 实验流程（5 阶段）

1. **初始化**：给集群第谷数据 + 基础几何代数；禁止任何现代天文学知识；
2. **第一轮**：假说集中在圆轨道（与当时旧理论一致）；D 单元残差很大；V 压低圆轨道；
3. **多轮迭代**：B 持续生成变形轨道（偏心圆、卵形……）；绝大多数被证伪淘汰；
4. **涌现临界点**：椭圆假说被生成 → C 推导方程 → D 残差显著下降 → V 高分保留 → 继续精炼；
5. **输出**：自主提出椭圆轨道假说，推导开普勒第二、第三定律，给出可检验预言（如周期-半长轴关系）。

## 4. 评估指标（判断"真涌现"而非查表）

1. **方程先于形态**：不直接输出"椭圆"；先输出几何方程，再自然导出轨道形态；
2. **迭代轨迹可见**：大量错误假说被生成、打分、淘汰的过程完整可查，不是一步到位；
3. **消融证明**：关掉 $V$ 后无法收敛、假说空间爆炸——价值调制是涌现必要条件。

## 5. 消融实验方案

| 消融 | 操作 | 预期结果 | 结论 |
|---|---|---|---|
| 关 $V$ | 移除价值调制单元 | 假说爆炸：无限生成复杂曲线拟合噪声 | $V$ 是收敛必要条件 |
| 关重组 | 移除 E 集群 | 卡在局部最优（偏心圆/均轮体系），无法跳出 | 重组是范式跃迁必要条件 |
| 单体 baseline | 单个集中式模型直接拟合/直推 | 至多内插已知范式，无法自发生成新本体假说 | 集体交互不可被单体替代 |

## 6. 预期失败模式

- **假说爆炸**：无 $V$ → 无限生成复杂曲线拟合噪声（过拟合）；
- **局部最优（均轮陷阱）**：卡在偏心圆/本轮均轮体系——局部一致性高但复杂；这正是范式跃迁难点的缩影。

# 开普勒原型 A–F 最小实现设计（阶段 1 可执行版）

> 本文把 `references/kepler-prototype.md` 的集群设计落成一份**最小实现规格**：
> 数据口径、六个单元（A/B/C/D/V/E）的接口与算法、黑板协议、评估与消融、
> 失败模式与审计。目标 = 第一版可跑通的"集体溯因闭环"（CPU 可跑，不含 LLM）。
> 设计纪律：任何单元不持有完整假说；单元只通过黑板文件交换状态；V 是唯一全局调制。

## 1. 数据（冻结语料 O_t0）

**生成器**（本地脚本，一次生成后冻结为数据文件）：

- 真实动力学：中心力场二体轨道（太阳引力，μ=1），每颗"行星"隐藏参数：
  偏心率 e ∈ [0.05, 0.6]、半长轴 a ∈ [0.8, 1.2]、近日点角 ω、初始平近点角 M0；
- 观测 = **仅位置** (x, y)（第谷只测位置），时间戳稀疏且不均匀（抖动 ±0.02），
  位置高斯噪声 σ=0.01；
- 规模：3 颗行星 × 每颗 ~200 观测点，覆盖 ≥3 个会合周期；
- **冻结与审计**：数据文件含 timestamps + (x,y)；审计脚本扫描全部输入/输出词表，
  禁止出现"ellipse/椭圆/focus/焦点/Kepler/开普勒"等 t>t0 术语；
- 基础工具（允许）：欧几里得几何原语（点/线/圆/圆锥曲线族）、代数求解器、
  牛顿迭代求根——**圆锥曲线作为数学对象属于 t0 前知识（Apollonius，~200 BC），
  不构成泄漏；泄漏的是"行星轨道=椭圆 + 太阳在焦点 + 等面积"这一物理假说**。

## 2. 六个单元（最小实现）

| 单元 | 接口 | 算法（v0） |
|---|---|---|
| **A 异常检测** | 观测文件 → `anomalies.json`: 每行星的残差序列 + 反常标记 | 拟合旧范式：正圆 + k 本轮（k=0..2），最小二乘；残差超过 3σ 的窗口标为反常 |
| **B 假说生成** | `anomalies.json` → `hypotheses.jsonl`：候选假说列表（含大量错误） | 从几何原语族采样：① 正圆 (cx,cy,r)；② 偏心圆 (c 圆 + 偏心点)；③ k-本轮叠圆 (k=1..3)；④ **一般圆锥曲线** (a,e,ω) + 行星过近日点时刻 t_p。每代 ≥64 条，参数从先验采样/变异 |
| **C 数理推导** | 单条假说 → 预言位置序列 `predictions.json` | 对圆锥曲线假说：开普勒方程 M = E − e·sinE 牛顿迭代 → 真近点角 → 位置；对本轮假说：直接几何叠加。输出与观测时刻对齐的预言 |
| **D 观测校验** | 预言 + 观测 → `score.json` | 残差 RMS + 卡方；**留出校验**：30% 观测时间不参与拟合（B 只用 70%），D 对留出段打分（可证伪性 F 的实测量） |
| **V 全局调制** | 全部 score + 假说 → 幸存集 | V(h)=w1·C+w2·S+w3·F−w4·K：C=卡方得分；S=参数数负分（本轮数 k 重罚）；F=留出段得分（能否预言未见时刻）；K=参数简并/冗余惩罚。每代保留前 ~8 条 |
| **E 重组** | 幸存集 → 下一代候选 | 参数交叉（两条假说的参数向量加权混合）+ 局部扰动（σ 随代数衰减）+ 结构变异（圆锥曲线↔偏心圆互转） |

**驱动循环**（`driver.py`）：Phase 0 审计 → for gen in 1..N: A(首代后只更新残差) →
B → C → D → V → E → 收敛检查（最好假说的留出误差 < 阈值 且 连续 3 代无改善）→
输出 `convergence.json` + `trace.jsonl`（全代际假说与分数——迭代轨迹证据）。

## 3. 文件布局（最小仓库）

```
kepler/
├── data/                   # 冻结观测（生成后只读）
│   ├── observations.json   # [{planet, t, x, y}, ...]
│   └── AUDIT.md            # 冻结审计记录
├── units/
│   ├── a_anomaly.py
│   ├── b_hypothesis.py     # 原语库 + 采样/变异
│   ├── c_derive.py         # 开普勒方程/本轮几何 → 预言
│   ├── d_verify.py         # 拟合/留出评分
│   ├── v_value.py          # V(h) 四分量
│   └── e_recombine.py
├── blackboard/             # 单元间唯一通信面（JSON 工件，带代数戳）
├── driver.py               # 主循环 + 收敛/预算控制
└── eval/
    ├── equation_first.py   # 方程先于形态检查器
    └── ablations.py        # 关 V / 关 E / 单体 baseline
```

**黑板协议**：每个工件 = `{gen, unit, payload, parents[], ts}`；单元只写自己的
文件名空间；driver 保证读到的工件代数 ≤ 当前代（无未来泄漏：单元看不到后续代）。

## 4. 评估（三件套，跑完必查）

1. **方程先于形态**：最终输出必须先是圆锥曲线方程（a, e, ω, t_p 的数值 + 焦点位置），
   由方程**自然导出**形态结论（e>0 → 椭圆；焦点处拟合出中心天体位置）；检查器拒绝
   任何先出现"椭圆"字样的输出；
2. **迭代轨迹**：`trace.jsonl` 必须显示：早期以正圆/偏心圆/本轮为主（旧范式），
   圆锥曲线假说中期出现并逐步压低误差与复杂度，最终收敛——不是一步到位；
3. **消融**（每次评测至少跑前两项）：
   - 关 V → 预期：本轮假说无限增殖拟合噪声（假说爆炸），收敛失败；
   - 关 E → 预期：卡在偏心圆/本轮局部最优（均轮陷阱），无法到达圆锥曲线；
   - 单体 baseline（单个模型/优化器直接拟合全部数据）→ 预期：能低误差拟合，
     但产出的是黑箱参数或高阶多项式，**无法给出方程先于形态的轨迹**——证明
     集体交互不可被单体替代。

## 5. 判定标准（阶段 1 通过 = 全部满足）

1. 收敛假说满足：圆锥曲线且 e ∈ [0.05, 0.6]（与真值同族），近日点/焦点方向
   与真值误差 < 15°，留出段预测误差 ≈ 训练段（不靠记忆）；
2. 三件套评估全过（方程先于形态 + 轨迹可见 + 至少两项消融符合预期）；
3. 泄漏审计通过（无未来术语、无形态关键词输入）；
4. 失败模式如实记录（若 10 代内不收敛，按"假说爆炸/均轮陷阱"归类并归档）。

## 6. 已知风险与对策

| 风险 | 症状 | 对策 |
|---|---|---|
| 假说爆炸 | 无 V 时无限增殖 | V 的 S/K 项 + 每代配额 |
| 均轮陷阱 | 高精度低简洁的偏心体系胜出 | S 项对 k 重罚 + E 的结构变异强制探索 |
| 噪声过拟合 | 留出误差远大于训练 | F 项（留出段）进 V，权重不低于 C 的 1/3 |
| 泄漏污染 | 输出/输入出现未来词 | Phase 0 审计 + 输出词表检查器（eval/equation_first.py 兼任） |

## 7. 实施预算

- 代码量：v0 ≈ 600–800 LOC（纯 Python + numpy；无训练、无 GPU）；
- 运行：单次完整 10–20 代循环 ≤ 10 分钟（CPU）；
- 依赖：`sklearn`（仅最小二乘，可选），其余 numpy；
- 里程碑：M1 数据生成+审计 → M2 单元 A–D 单跑（拟合圆）→ M3 加 V/E 闭环 →
  M4 评估三件套 + 消融 → M5 收敛判定与归档。
